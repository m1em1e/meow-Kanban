# MeowKanban 接口文档

## 1. 文档说明

本文档基于当前静态原型和项目规划拟定，面向后续 Spring Boot REST API 实现。

- API 前缀：`/api/v1`
- 数据格式：`application/json; charset=UTF-8`
- 时间格式：`yyyy-MM-dd HH:mm:ss`
- 日期格式：`yyyy-MM-dd`
- 默认时区：`Asia/Shanghai`
- 认证方式：早期可使用 Session，后续可切换为 Bearer Token

## 2. 通用响应结构

项目已有统一返回类 `Result<T>`，接口统一返回以下结构。

```json
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

### 2.1 状态码约定

| code | 含义 |
| --- | --- |
| 1 | 成功 |
| 0 | 业务失败 |
| 400 | 请求参数错误 |
| 401 | 未登录或登录失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 数据冲突 |
| 500 | 系统异常 |

HTTP 状态码用于表达协议层结果，`code` 用于表达业务层结果。

## 3. 通用枚举

### 3.1 任务优先级

| 值 | 说明 |
| --- | --- |
| `normal` | 普通 |
| `urgent` | 高优先级 |

### 3.2 成员角色

| 值 | 说明 |
| --- | --- |
| `owner` | 看板拥有者 |
| `admin` | 管理员 |
| `member` | 普通成员 |
| `viewer` | 只读成员 |

### 3.3 任务活动类型

| 值 | 说明 |
| --- | --- |
| `create` | 创建任务 |
| `update` | 更新任务 |
| `move` | 流转任务状态 |
| `comment` | 新增评论 |
| `attach` | 新增附件 |
| `delete` | 删除资源 |

## 5. 看板接口

### 5.1 获取看板列表

`GET /api/v1/boards`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 按看板名称搜索 |
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页数量，默认 20 |

响应：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "total": 1,
    "records": [
      {
        "id": 1,
        "name": "MeowKanban",
        "description": "轻量项目看板",
        "ownerId": 1,
        "visibility": 0,
        "createdTime": "2026-06-17 09:00:00",
        "updatedTime": "2026-06-17 09:00:00"
      }
    ]
  }
}
```

### 5.2 创建看板

`POST /api/v1/boards`

请求体：

```json
{
  "name": "MeowKanban",
  "description": "轻量项目看板",
  "visibility": 0
}
```

### 5.3 获取看板详情

`GET /api/v1/boards/{boardId}`

响应中的 `sections` 用于渲染看板列，`members` 用于顶部成员菜单。

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "id": 1,
    "name": "MeowKanban",
    "description": "轻量项目看板",
    "visibility": 0,
    "sections": [
      {
        "id": 1,
        "code": "backlog",
        "title": "待规划",
        "sortOrder": 10
      }
    ],
    "members": [
      {
        "userId": 1,
        "nickname": "林夏",
        "avatarResourceId": null,
        "role": "owner",
        "lastLoginTime": "2026-06-17 09:00:00"
      }
    ]
  }
}
```

### 5.4 更新看板

`PUT /api/v1/boards/{boardId}`

请求体：

```json
{
  "name": "MeowKanban",
  "description": "轻量项目看板",
  "visibility": 0
}
```

### 5.5 删除看板

`DELETE /api/v1/boards/{boardId}`

建议采用软删除，避免误删任务数据。

```json
{
  "code": 1,
  "msg": "success",
  "data": [
    {
      "id": 1,
      "code": "backlog",
      "title": "待规划",
      "sortOrder": 10,
      "taskCount": 3
    }
  ]
}
```

### 7.2 创建分区

`POST /api/v1/boards/{boardId}/sections`

请求体：

```json
{
  "title": "待发布"
}
```

服务端生成唯一 `code`，用于前端状态流转和任务归类。

### 7.3 重命名分区

`PUT /api/v1/boards/{boardId}/sections/{sectionId}`

请求体：

```json
{
  "title": "验收中"
}
```

### 7.4 调整分区顺序

`PUT /api/v1/boards/{boardId}/sections/sort`

请求体：

```json
{
  "sectionIds": [1, 2, 3, 4, 5]
}
```

### 7.5 删除分区

`DELETE /api/v1/boards/{boardId}/sections/{sectionId}`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `fallbackSectionId` | number | 是 | 删除后任务迁移到的目标分区 |

当分区内存在任务时，必须提供 `fallbackSectionId`。

## 8. 任务接口

### 8.1 获取任务列表

`GET /api/v1/boards/{boardId}/tasks`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 搜索任务编号、标题、描述、负责人、标签 |
| `sectionId` | number | 否 | 按分区筛选 |
| `priority` | string | 否 | `normal` / `urgent` |
| `blocked` | boolean | 否 | 是否阻塞 |
| `mine` | boolean | 否 | 是否只看当前用户负责 |
| `hideDone` | boolean | 否 | 是否隐藏完成任务 |
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页数量，默认 50 |

响应：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "total": 7,
    "records": [
      {
        "id": 1,
        "taskNo": "MK-102",
        "title": "梳理移动端任务详情信息架构",
        "description": "确认任务详情页需要展示的字段、评论入口、附件入口和状态流转规则。",
        "ownerId": 1,
        "ownerName": "林夏",
        "dueDate": "2026-06-04",
        "sectionId": 1,
        "sectionCode": "backlog",
        "sectionTitle": "待规划",
        "priority": "urgent",
        "blocked": false,
        "tags": ["产品", "信息架构"],
        "createdTime": "2026-06-17 09:00:00",
        "updatedTime": "2026-06-17 09:00:00"
      }
    ]
  }
}
```

### 8.2 创建任务

`POST /api/v1/boards/{boardId}/tasks`

请求体：

```json
{
  "sectionId": 1,
  "title": "新建需求待补充",
  "description": "这是一个用于演示新增流程的占位任务，可继续扩展为表单弹窗。",
  "ownerId": 1,
  "dueDate": "2026-06-10",
  "priority": "normal",
  "blocked": false,
  "tags": ["草稿"]
}
```

## 13. 校验规则

| 字段 | 规则 |
| --- | --- |
| `username` | 必填，长度 3-50，仅允许字母、数字、下划线、短横线 |
| `password` | 登录时必填，长度 6-100 |
| `board.name` | 必填，长度 1-100 |
| `board.visibility` | 必填，`0` 私有，`1` 公开 |
| `section.title` | 必填，长度 1-50，同一看板内不建议重复 |
| `task.title` | 必填，长度 1-200 |
| `task.description` | 可空，最长 2000 |
| `task.dueDate` | 可空，格式 `yyyy-MM-dd` |
| `task.tags` | 单个标签最长 30，单任务建议最多 10 个 |
| `comment.content` | 必填，长度 1-2000 |

## 14. 权限规则

| 操作 | owner | admin | member | viewer |
| --- | --- | --- | --- | --- |
| 查看看板 | 是 | 是 | 是 | 是 |
| 创建任务 | 是 | 是 | 是 | 否 |
| 编辑任务 | 是 | 是 | 是 | 否 |
| 删除任务 | 是 | 是 | 否 | 否 |
| 管理分区 | 是 | 是 | 否 | 否 |
| 管理成员 | 是 | 是 | 否 | 否 |
| 删除看板 | 是 | 否 | 否 | 否 |

## 15. MVP 实现建议

第一阶段优先实现以下接口：

1. `GET /api/v1/boards/{boardId}`
2. `GET /api/v1/boards/{boardId}/tasks`
3. `POST /api/v1/boards/{boardId}/tasks`
4. `PUT /api/v1/boards/{boardId}/tasks/{taskId}`
5. `PUT /api/v1/boards/{boardId}/tasks/{taskId}/move`
6. `POST /api/v1/boards/{boardId}/sections`
7. `PUT /api/v1/boards/{boardId}/sections/{sectionId}`
8. `DELETE /api/v1/boards/{boardId}/sections/{sectionId}`

认证、评论、附件和统计可以在核心看板稳定后逐步补齐。
